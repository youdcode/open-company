# Memory

What the team must remember from one day to the next, when it is not already in another file.
Facts and decisions only, one line each, newest at the bottom. Written with `node tools/memory.mjs`.

Read at the start of every session. Long documents go in `departments/`, prospect data in
`prospecting/`, dated decisions in `journal.md`: this file stays short (60 lines max).
